# Kleiderspenden-Portal

Fallstudie IPWA01-01 - Programmierung von Webanwendungsoberflächen

## Funktionen
- Registrierung von Kleiderspenden
- Zwei Modi: Abholung vs. Übergabe an der Geschäftsstelle
- PLZ-Validierung (Berliner Postleitzahlen)
- Responsives Design für Desktop und Tablet
- Dynamische Formularvalidierung
- Bestätigungsseite mit Datum und Uhrzeit

## Tech-Stack
- HTML5, CSS3, JavaScript
- Bootstrap 5.3
- Vue.js 3      

## Projektstruktur
- index.html          
- registrierung.html  
- style.css
